## Les trois pièges qui font perdre le plus de temps

Ils reviennent assez souvent pour mériter d'être dits ici, avant tout le reste.

**1. Créez les classes avant d'importer les élèves.** Sans classes, les élèves sont créés mais **non inscrits**, et vous verrez « 96 créés, 0 inscrits ». La colonne Classe de votre fichier doit correspondre **exactement** au libellé de la classe.

**2. Mettez une date d'échéance sur les factures.** Sans elle, une facture impayée n'est **jamais** signalée en retard et n'entre pas dans les relances.

**3. Datez vos trimestres.** Dans Structure → Découpage de l'année. Sans dates, les absences ne peuvent pas être comptées sur les bulletins — l'application préfère ne rien afficher plutôt qu'un zéro faux.
