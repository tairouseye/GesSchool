🔒 Le numéro seul ne suffit jamais

Il faut toujours une preuve : le code parent la première fois, puis le mot de passe ou l'empreinte. Connaître le numéro d'un parent ne donne accès à rien.

👪 Un numéro = un parent = tous ses enfants

Si la même personne figure sur plusieurs fiches (une par enfant), elle les retrouve toutes. Si deux personnes différentes partagent le numéro, il est bloqué jusqu'à correction.

📧 Rien ne change pour les comptes existants

Un parent déjà inscrit avec son e-mail continue comme avant. Il pourra ajouter son numéro depuis « Mon compte ».
