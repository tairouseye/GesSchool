# Tutoriels vidéo GesSchool — scripts

Douze vidéos courtes : cinq pour les **parents** (filmées sur téléphone), sept pour les **directions et la gestion** (filmées sur ordinateur). Chaque vidéo montre **un seul geste**, en 1 à 3 minutes.

Pour chaque vidéo : ce qu'il faut préparer, puis le déroulé plan par plan — **ce qu'on voit à l'écran** et **ce qu'on dit**. Le texte à dire est écrit pour être lu à voix haute, phrases courtes, en vouvoyant.

*Rédigé le 30/10/2026 d'après l'appli v2.284.1 (tableau de bord « À faire aujourd'hui », fiche élève à onglets, logo plume).*

---

## Avant d'enregistrer

### 1. Filmez sur l'école de démonstration, jamais sur une vraie école

Une vidéo circule : on ne doit y voir **ni le nom, ni la photo, ni les paiements d'un vrai enfant**. Utilisez l'école **TutTank_Demo** (ou créez-en une autre de démonstration) et remplissez-la avec des élèves fictifs. Vérifiez chaque plan avant de publier : une notification ou un nom réel peut passer à l'écran.

Préparez sur l'école de démonstration :
- deux ou trois classes (CI A, CM1 A…) et une dizaine d'élèves fictifs ;
- un compte **parent de démonstration** relié à un élève, avec une facture impayée ;
- un compte **direction** et un compte **comptable** de démonstration ;
- un petit fichier Excel de 5 élèves pour la vidéo d'import.

### 2. Enregistrer l'écran

| Sur | Comment |
|---|---|
| **Ordinateur Windows** | **Windows + Alt + R** démarre et arrête l'enregistrement de la fenêtre active (Xbox Game Bar). Activez le micro dans la Game Bar (Windows + G → Capture → micro). Les vidéos vont dans *Vidéos → Captures*. |
| **Android** | Volet de raccourcis → **Enregistrement d'écran** (choisir « avec le son du micro »). |
| **iPhone** | Centre de contrôle → **Enregistrement de l'écran** ; appui long sur le bouton pour activer le micro. |

Conseils :
- **Ordinateur** : fenêtre du navigateur en plein écran, zoom à 110–125 % (Ctrl +) pour que le texte se lise sur un téléphone.
- **Téléphone** : mode « Ne pas déranger » (pas de notification qui s'affiche), batterie et réseau visibles mais propres.
- Bougez la souris **lentement**, marquez une pause d'une seconde avant chaque clic.
- Enregistrez la voix **à part** si le premier essai hésite : on la pose ensuite sur l'image au montage.

### 3. Monter

**Clipchamp** (déjà installé sur Windows 11) ou **CapCut** (gratuit, aussi sur téléphone) suffisent :
1. couper les hésitations et les temps de chargement ;
2. ajouter un **titre** de 2 secondes au début (le logo plume + le titre de la vidéo) et une **fin** de 3 secondes (« GesSchool — gesschool.gesprosn.org ») ;
3. ajouter les **sous-titres automatiques**, puis les relire : beaucoup de vidéos sont regardées **sans le son** sur WhatsApp ;
4. une musique douce, très bas, sous la voix ;
5. exporter en **1080p**. Format **vertical (9:16)** pour les vidéos parents, **horizontal (16:9)** pour les vidéos direction.

## Vidéos pour les parents (sur téléphone, format vertical)

### P1 — Créer son compte et retrouver son enfant · 1 min 30

**Préparer** : un code parent de démonstration non utilisé (fiche de l'élève → onglet Aperçu → Responsables → **Code parent**). Une adresse e-mail de test.

| Plan | À l'écran | À dire |
|---|---|---|
| 1 | Titre : « Créer votre compte parent » | « Dans cette vidéo, vous allez créer votre compte GesSchool et retrouver votre enfant. Il vous faut le code remis par l'école. » |
| 2 | Le code écrit sur un papier ou reçu par WhatsApp | « L'école vous donne un code de huit caractères, par exemple 3F9A2B7C. Gardez-le sous la main. » |
| 3 | Ouvrir gesschool.gesprosn.org | « Ouvrez GesSchool dans le navigateur de votre téléphone. Vous pouvez aussi scanner le QR code affiché à l'école. » |
| 4 | Onglet **Inscription**, saisir l'e-mail et le mot de passe, **Créer le compte** | « Touchez Inscription. Entrez votre adresse e-mail, choisissez un mot de passe, puis touchez Créer le compte. » |
| 5 | Écran de bienvenue → **Je suis un parent** | « GesSchool vous demande qui vous êtes : touchez Je suis un parent. » |
| 6 | Saisir le code → **Rejoindre l'établissement** | « Entrez le code de l'école, puis touchez Rejoindre l'établissement. » |
| 7 | L'écran **Mes enfants** avec la carte de l'enfant | « Voilà : votre enfant apparaît. Vous avez plusieurs enfants, même dans des écoles différentes ? Gardez ce compte et touchez Ajouter un enfant avec le nouveau code. Ne créez pas un second compte. » |
| 8 | Fin | « Dans la prochaine vidéo : installer l'appli et vous connecter avec votre empreinte. » |

**Préparer** : une facture impayée sur l'élève de démonstration ; les numéros mobile money de l'école de démonstration renseignés ; une capture d'écran de paiement fictive pour la preuve. **Ne montrez pas un vrai paiement ni un vrai numéro de transaction.**
